# 📚 Mebook

읽은 책을 한 권씩 **쌓아 올리는** 나만의 독서 기록 웹사이트.

## 기능

- **회원가입 / 로그인**: 계정마다 책·독후감·출석 기록이 따로 저장돼요 (비밀번호는 해시로 저장).
- **책장 (책 / 그래프 탭)**: 완독일 기준으로 1~12월 칸에 책 표지가 위로 쌓여요. 칸 위 숫자는 그 달 권수.
- **책 추가**: Google Books 검색으로 제목·저자·표지를 자동으로 채우거나 직접 입력. "읽는 중" 상태도 지원.
- **독후감**: 책장에서 책을 누르면 별점과 독후감을 쓸 수 있어요. 독후감을 쓴 책에는 ✎ 표시.
- **출석 달력**: 날짜를 눌러 출석 체크 + 읽은 쪽수·메모 기록. "오늘 출석하기" 버튼, 완독한 책도 달력에 표시.
- **통계**: 월 평균 읽은 책, 책석률(책 읽은 날 ÷ 지난 날), 연속 출석일, 월별 완독·책석률 그래프.

## 실행 방법

```bash
cd mebook
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

브라우저에서 http://127.0.0.1:5000 접속 → 회원가입 후 사용.

데이터는 `mebook/instance/mebook.db`(SQLite)에 저장되고, 이 폴더는 git에 올라가지 않아요.

| 환경변수 | 설명 |
| --- | --- |
| `PORT` / `HOST` | 서버 포트·주소 (기본 5000 / 127.0.0.1) |
| `MEBOOK_SECRET_KEY` | 세션 암호화 키 (없으면 자동 생성) |
| `MEBOOK_DB` | DB 파일 경로 |
